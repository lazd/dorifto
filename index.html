Tuning

Changes apply immediately to the selected drive mode. Each mode keeps separate settings. Try raising rear peak grip if the rear steps out too quickly.

Engine, steering, tire grip and response

Front/rear peak factors multiply the active mode's base friction independently. Restore defaults resets only this mode. Car reset keeps your tuning; reloading restores defaults.

Custom course

Choose a course length and independent preferences from 0 (avoid) to 1 (strongly favor). The preferences do not need to add up to 1. Changes apply only when you generate.

Generation preferences

Elevation 0 is completely flat. Closed circuits still need return bends. Course length targets 1–5 km, within 5%. Tight corners include switchbacks. All layouts keep safe road clearance and at least a 22 m turn radius.
